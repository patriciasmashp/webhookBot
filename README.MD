# Кейс бот на веб хуках
Для успешной записи в гугл таблицы:
1. Сгенерируйте через google console файл с доступами
2. Переименуйте его в gsheet_creds.json
3. Поместите в корневую папку бота (/app)
4. Напишите мне, я добавлю вас в пользователей и дам ссылку на таблицу
5. После этого запустите проект, в консоли появится OAuth ссылка для авторизации.
6. После авторизации гугл таблицы заработают
